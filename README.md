## 🎨 Customization Made Easy

### 1️⃣ Update Your Info

Edit `data/portfolioData.js`:

```javascript
export const personalInfo = {
  name: "Your Name",
  title: "Your Professional Title",
  email: "your@email.com",
  bio: "Your amazing bio..."
}
```

### 2️⃣ Add Your Projects

```javascript
export const projects = [
  {
    title: "Awesome Project",
    description: "What it does",
    technologies: ["React", "Node.js"],
    link: "https://project.com",
    github: "https://github.com/..."
  }
]
```

### 3️⃣ Customize Colors

**Option A:** CSS Variables in `app/globals.css`
```css
:root {
  --primary: #3b82f6;
  --secondary: #8b5cf6;
}
```

**Option B:** Tailwind Config in `tailwind.config.js`
```javascript
module.exports = {
  theme: {
    extend: {
      colors: {
        brand: '#your-color'
      }
    }
  }
}
```

### 4️⃣ Optimize Assets

```bash
# Recommended image specs
- Width: 1200px max
- Format: WebP or AVIF  
- Size: Under 200KB
- Location: public/images/
```

## 🚀 Deploy in Minutes

### Vercel (Recommended)

```bash
# Push to GitHub, then:
1. Visit vercel.com/new
2. Import your repository  
3. Click Deploy
4. Done! ✨
```

**One-Click Deploy:**
```
https://vercel.com/new/clone?repository-url=https://github.com/yourusername/my-portfolio
```

### Netlify

```bash

# Then deploy via:
- Netlify CLI: netlify deploy
- GitHub integration (auto-deploy)
- Drag & drop to netlify.com
```
